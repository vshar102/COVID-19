# COVID-19 State-wise Comorbidity and Hospitalization Analysis

🎯 Project Overview

Developed comprehensive healthcare analytics platform supporting pandemic response efforts through predictive modeling of hospitalization patterns and comorbidity risk factors across geographic regions.

💼 Business Problem

Healthcare officials and policymakers needed data-driven insights for resource allocation, risk population identification, and strategic pandemic response planning during unprecedented health crisis.

🔧 Technical Solution

Analyzed comorbidity rates, hospitalization trends, and mortality rates across US states using Linear Regression methodology. Applied advanced feature selection techniques to identify 4 critical features from comprehensive 135-feature dataset for optimal model performance.

📊 Key Results

Comprehensive multi-state analysis framework
Optimized feature selection: 4 key features from 135 total features
Advanced statistical modeling for healthcare insights

💰 Business Impact

Informed strategic resource allocation decisions, enabled targeting of high-risk populations, and provided actionable intelligence for healthcare professionals and officials to make data-driven decisions for effective COVID-19 response strategies.
